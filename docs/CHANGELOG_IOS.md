# 更新日志

## 0.3.8+65（ios-0.3.8）

### 🐛 修复
- **本地图书导入（iOS）**：新增 iOS 原生文件选择器（UIDocumentPicker），适配 TXT / EPUB / PDF / MOBI / ZIP 选择导入；TXT 内置编码探测（UTF-8 / UTF-16 / GB18030 / GBK），乱码问题一并解决。
- **隐藏系统状态栏（iOS）**：阅读设置 → 操作 → “隐藏系统状态栏”开关现在真正生效，阅读页进入全屏沉浸状态。
- iOS 端隐藏不可用的“从网盘导入 / 扫描本地文件夹”菜单，避免误触报错。

### ✨ 沿用上一版修复
- iOS 在线功能（书库 / 更新 / 正文 / 搜索 / 登录 / 出版目录）为纯 Dart 桥实现，appver 算法已复刻。

未签名 IPA，仅限 TrollStore/巨魔侧载安装。部署目标 iOS 13.0。
